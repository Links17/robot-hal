# v0.5.0-rc qualification evidence

This template separates software release conformance from external physical
hardware qualification. A completed release directory proves only the
artifact and software checks recorded in its `conformance-report.json`; it
does not promote physical hardware status.

broker executable only when its target matches the local host. Evidence for
other targets must be supplied by the corresponding hosted platform job.
