# v0.4.0 Camera external qualification record

This record is reserved for native hardware evidence. It is intentionally separate from
[hardware-free acceptance](v0.4.0-acceptance.md). A cross-compile, virtual adapter, or ignored test
that was not run on its target does not change a `Pending` result to `Passed`.

Do not record serial numbers, full device paths or symbolic links, shared-memory mapping names,
capability tokens, raw frame bytes, or images. Use a redacted HAL resource ID and an external
retained-log reference where needed.

## Result interpretation

- `Passed`: every required observation in the adapter runbook succeeded for the recorded fixture.
- `Partial`: supported-format or platform limitation was observed and recorded; it is not a release
  pass unless the release owner explicitly accepts that limitation.
- `Blocked`: the required target, driver, permission, fixture, or safety condition was unavailable.
- `Failed`: a required behavior did not meet the contract. File an implementation defect before
  claiming qualification.
